# 球体の点を巡る光のリボン

ローカルTOPの既存点群の色・明度で、リボンの動きを表現する。連続した線の専用メッシュは削除した。点数（PC900/スマホ540）・サイズ・位置・振動停止・輪郭線なし・黒基調は維持。

## 表現

- 傾いた軌道を17秒周期で光が巡る。球体の各点と軌道の距離・光の通過時刻により発光を計算する。
- 先端の点は白〜淡い金色へ明るくなり、通過後の点は薄い金色へ減衰する。常時一周する線は描かない。
- 点群自身の回転を補正し、光跡とフレアの軌道を一致させる。奥側は小さく控えめ、手前は明るい既存の前後差を維持。
- 手前から奥へ抜ける際の約1.3秒のフレアは維持し、位置は球面上の先端に合わせる。
- 内部へ進むと光のリボン・フレアは消える。

## 負荷・検証

専用のリボンメッシュ・形状・マテリアルを削除し、既存の点群シェーダーに発光処理を統合。追加の画像・外部ライブラリー・ポストプロセスなし。既存の非表示タブ停止・reduced-motion静止を維持。

ESLint/Prettier/ビルド/diff --check通過。PC・390px幅で描画・エラーなし、点数900/540・拡縮1.000維持、横はみ出しなしを確認。本番変更なし。

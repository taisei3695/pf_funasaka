# TOP初回表示・スマートフォン向け描画の調整

ローカル `http://localhost:8888/` のみ変更。本番は更新していません。

## 変更内容

- 球体の動的モジュールをTOPのheadからmodulepreload。メインJS実行後に発見する通信の連鎖を短くしました。他のページでは球体を先読みしません。
- JavaScript有効時は球体用スクロール領域を先に確保し、モジュール到着前後の大きなレイアウト変更を減らしました。JS無効時・WebGL失敗時・動きを減らす設定・強制配色では従来の読みやすい表示に戻ります。
- サーバー側の名前・見出しを描画する機会を確保した後に、WebGLを準備します。ページ離脱時には待機中のフレームも破棄します。
- 768px未満で球面・大気に共用するメッシュを12,096三角形から2,976三角形へ約75%削減。点の数・丸い輪郭・光・リズムの設定は維持。
- スマートフォン幅のDPR上限を1.25から1へ変更。高DPR端末では最大描画ピクセル数を従来比36%削減。画面上のレイアウトサイズと点の見た目の大きさは維持します。
- モバイル30fps / PC60fpsの既存上限を維持。描画処理の平均実行時間が継続して予算を超えた場合だけ、バッファ解像度を最大60%まで段階的に落とします。ブラウザーの非表示・遮蔽に伴うrAF間隔だけでは品質を落としません。
- タブ非表示・画面外で描画を止める既存処理、WebGLコンテキスト復旧、暗幕終了後のグリッチ・装飾線の順序は維持。
- SKILLSにGit（3年・実務経験あり・ソースコードのバージョン管理）を追加。年数・実務経験は本人確認済み。

## 計測

390px幅・DPR1の同一ローカルブラウザーで取得。応答時間の揺れを除くため、HTML応答開始からの追加時間も併記します。

| 項目 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 球体モジュール取得開始 − TTFB | 273ms | 17ms |
| 球体の初フレーム − TTFB | 446ms | 310ms |
| First Contentful Paint − TTFB | 311ms | 194ms |
| メッシュの三角形数 | 12,096 | 2,976 |

PC幅ではFCP−TTFBは195msから158ms。球体の初フレーム−TTFBは253msから294msで、テキストの描画を先にする処理の分だけ遅れるサンプルでした。全体の表示時間やスコアの一律改善は保証していません。

JavaScriptから描画を送る処理の平均実行時間はスマートフォン幅で約1.5ms、PC幅で約0.2msのサンプルでした（GPU完了までの時間を直接測った値ではありません）。一方、検証用ブラウザーのrAF配信間隔は測定間で大きく変動したため、fpsを実機性能の指標にはしていません。実機スマートフォンのGPU・CPUや通信速度はこの環境では再現していません。

証跡：`work/music-accents-20261018/top-mobile-before.json`、`top-mobile-after.json`、`top-desktop-before.json`、`top-desktop-after.json`。一時的な計測用コードは削除済み。

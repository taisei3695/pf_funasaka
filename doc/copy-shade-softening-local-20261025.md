# 文字の背後の暗いグラデーション調整（ローカルのみ）

2026年10月25日。読みやすさを保ちながら暗い背景面を周囲へ自然になじませる依頼に対応。

## 調整

- TOPの説明文・About・Experience・Contactの下地は、上下3rem・左右4remの範囲で段階的に透明へ変化させる。文字直下の暗さは維持し、矩形の縁を目立ちにくくした。
- FVは左右・上下のフェード範囲を広げ、左端も透明から始めるよう変更。球体が文字背後へ入る箇所では暗さを維持。
- 詳細本文・メタ情報、一覧の説明文、プライバシーポリシーは、上下4rem・左右8remの広いフェードに変更。背景の光と暗い本文面の急な境界を和らげた。
- SKILLSは中央の暗さを88%から84%へ微調整し、上下のフェードを8remから12remへ延ばして複数段階で変化させた。
- 広がった装飾による横はみ出しを防ぐため、下層ページのメイン領域に`overflow-x: clip`を指定。スクロールコンテナーは新設しない。
- ぼかしフィルター、追加のアニメーション、JavaScript処理は増やしていない。

文字色・サイズ・ウェイト、新しい案件画像、球体・光・暗幕のJavaScript、DB・投稿・設定は変更していない。本番未反映。

## 確認

- Stylelint・Prettierチェック、WordPressテーマビルド成功。
- TOP・一覧・代表詳細・プライバシーポリシー・Contactを320・375・768・1280pxで確認し、最終版は横はみ出しなし。
- PCのFV・Experience・詳細・プライバシーポリシー、375pxのSKILLSを目視確認。実機・全アニメーション時点のコントラスト適合を保証する検査は未実施。

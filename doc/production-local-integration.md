- 下書きだったプライバシーポリシー（ローカルID 3）を公開し、標準のプライバシーポリシー設定に指定した。公開中の本番本文と `post-data/privacy-policy.html` の表示テキストが一致したため、編集可能なWordPressブロック形式を保って反映した。

## ローカル用に維持・調整した内容

- `home` / `siteurl` は `http://localhost:8888`。固定ページのIDは本番の数値を一括コピーしない。
- 現在のテーマ・WebGL・スクロール演出・フォント・カードホバーを保持した。
- 制作実績15件について投稿行・全メタ・タクソノミー関連付けの変更前後ハッシュが一致した。並び順、C++追記、公開・非公開の設定も保持した。
- 使用中プラグインは変更していない。Simple Page Orderingを保持した。
- GA4の本番測定IDは取得記録に残し、ローカルのSEO設定の測定ID欄は空欄にした。開発中の閲覧を本番GA4へ送信しない。

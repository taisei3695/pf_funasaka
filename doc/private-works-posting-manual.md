# 非公開実績の投稿マニュアル

`schiff-web.com` のWordPressで非公開実績を追加・更新する手順です。実績の文章は管理画面で登録し、画像はFTPで専用フォルダーへ配置します。閲覧者にはBasic認証用の情報と非公開実績のURLを案内します。

## 登録前に用意するもの

| 項目 | 用意する内容 |
| --- | --- |
| 実績の情報 | タイトル、サイト種別、担当範囲、使用技術、概要、実装内容 |
| メイン画像 | 表示幅の2倍を目安にしたWebP。現在の詳細ページに合わせる場合は2560 × 1600px |
| WordPress | [管理画面](https://schiff-web.com/wp-admin/)へログインできること |
| FTP | `schiff-web.com` の専用画像フォルダーへアップロードできること |
| 閲覧確認 | Basic認証ユーザー `privateviewer` と設定済みのパスワード |

掲載する文章・画像は、案内する相手に見せてよい内容を用意します。認証用パスワードは、このマニュアルや投稿の文章には記載しません。

初回は [非公開実績一覧](https://schiff-web.com/private-works/) を開き、Basic認証でログインできることを確認してください。2026年10月5日時点では、未認証アクセスに認証を要求することを確認済みです。認証後の一覧・詳細・画像の表示は、初回登録時に確認する項目です。

## 画像の配置

1. メイン画像をWebPで用意します。現在の仕組みでは、1実績につき1枚を登録できます。
2. ファイル名は半角英小文字・数字・ハイフン・アンダースコアを使います。例：`project-a-main.webp`。
3. FTPで次のフォルダーへアップロードします。

```text
/schiff-web.com/private-media/
```

このフォルダーは `public_html` と同じ階層にあります。サーバー内の実際の場所は `/home/schiff/schiff-web.com/private-media/` です。

```text
schiff-web.com/
├── public_html/       WordPressの公開領域
└── private-media/     非公開実績の画像
    └── project-a-main.webp
```

WordPressの「メディア」、アイキャッチ、SEO SIMPLE PACKのOGP画像には、非公開実績の画像をアップロードしないでください。これらは公開画像URLで取得できるため、実績ページのBasic認証では保護できません。

## WordPressでの新規登録

1. 管理画面の **「制作実績 → 新規追加」** を開きます。
2. タイトルを入力します。例：`A社 コーポレートサイト`。
3. 「制作実績設定」の「掲載範囲」で **「非公開実績（サーバーのBasic認証が必要）」** を選びます。
4. 次の表を参考に、各項目を入力します。

| 入力項目 | 入力内容と例 |
| --- | --- |
| サイト種別【必須】 | `Corporate Website`、`コーポレートサイト`など |
| 担当範囲【必須】 | 実際に担当した内容。例：`Coding / WordPress / JavaScript` |
| サブタイトル | タイトルを補足する短い説明。不要なら空欄 |
| 使用技術 | 実際に使用した技術へチェック |
| 制作区分 | 「許可を得たクライアントワーク」「自主制作」など、該当する項目 |
| 非公開画像の保管キー | 専用フォルダー内のファイル名。例：`project-a-main.webp` |
| 概要 | サイトの目的、対象、担当した作業の概要 |
| 実装内容 | WordPress化、レスポンシブ対応、JavaScriptの処理など、実装した内容 |
| 公開サイトURL | 詳細ページから案内できる実際のURL。案内しない場合は空欄 |

このテーマでは「概要」「実装内容」を詳細ページの文章として表示します。新規登録では「旧制作内容（既存データ用）」を使いません。「クライアント名（任意）」「制作期間（任意）」は現在の詳細ページに表示されないため、掲載したい情報は概要へ記載します。

「公開サイトURL」を入力すると、非公開詳細にも外部サイトへのリンクが表示されます。リンク先のサイトは、そのサイト側の認証設定で保護してください。

準備中は「下書きとして保存」を使います。下書きの実績は、非公開実績一覧にも表示されません。

### 保管キーの入力例

保管キーは、`private-media` を起点にしたファイルの場所です。URLやサーバー内の絶対パスは入力しません。

| FTPで配置した場所 | 「非公開画像の保管キー」への入力 |
| --- | --- |
| `/schiff-web.com/private-media/project-a-main.webp` | `project-a-main.webp` |
| `/schiff-web.com/private-media/project-a/main.webp` | `project-a/main.webp` |

フォルダーを分ける場合は、FTPで `private-media` の中に `project-a` を作り、その中へ `main.webp` をアップロードします。保管キーには先頭の `/`、`private-media/`、日本語、空白、`..` を含めません。対応形式はWebP、JPEG、PNG、AVIFです。

画像を未設定にした場合や、保管キーとファイルが一致しない場合は画像を表示しません。画像用の枠は残るため、登録後に見た目を確認してください。

## 非公開での保存

1. タイトル下のパーマリンクで、URLの末尾に使う文字列（スラッグ）を確認します。例：`project-a`。まだパーマリンクが表示されない場合は、先に下書き保存してから確認します。編集する場合は半角英小文字・数字・ハイフンで指定します。
2. 「掲載範囲」が「非公開実績（サーバーのBasic認証が必要）」になっていることを確認します。
3. 右側の「公開」欄で、「公開状態」の「編集」を押し、「非公開」を選んで「OK」を押します。
4. 保存ボタンを押します。新規投稿では「非公開で公開」、保存済みの投稿では「更新」など、状態に応じた表示になります。
5. 保存後、投稿の公開状態が「非公開」になっていることを確認します。

「掲載範囲」とWordPressの公開状態は、どちらも非公開にそろえます。このテーマは掲載範囲に合わせて投稿状態を同期しますが、保存後の表示も確認してください。WordPressの「パスワード保護」は今回のBasic認証とは別の機能なので、ここでは「非公開」を選びます。

掲載後は投稿日が新しい実績から並びます。文章を更新するだけでは並び順は変わりません。日付を変更する場合は、現在または過去の日時を指定してください。

## 閲覧の確認

まず、WordPress管理画面へログインしていないブラウザーで確認します。Basic認証情報が残っていない別ブラウザー、または新しいシークレットウィンドウを使ってください。

| 確認するURL | 確認する内容 |
| --- | --- |
| `https://schiff-web.com/private-works/` | 認証画面が出る。ログイン後、登録した実績が一覧に出る |
| `https://schiff-web.com/private-works/project-a/` | 自分で指定したスラッグの詳細ページに文章と画像が出る |
| 公開トップページと `/works/` | 非公開実績が表示されていない |
| [実績のサイトマップ](https://schiff-web.com/wp-sitemap-posts-works-1.xml) | 非公開実績のURLが含まれていない |

詳細ページのURLは、非公開実績一覧の作品リンクから開くと確認できます。上の `project-a` は入力例なので、実際のスラッグに置き換えます。

閲覧者へ案内するのは、非公開実績のURLとBasic認証用のユーザー名・パスワードです。WordPress管理画面のログイン情報は共有しません。

現在のBasic認証でログインした相手は、一覧にある非公開実績をすべて閲覧できます。作品ごとの閲覧制限は設けていないため、認証情報は一覧全体を見せてよい相手にだけ共有してください。

## 登録後の修正と掲載停止

**文章の修正：** 「制作実績」の一覧から対象を編集し、概要・実装内容などを変更して「更新」を押します。

**画像の差し替え：** FTPで新しい画像を専用フォルダーへ配置し、「非公開画像の保管キー」を新しいファイル名へ変更して「更新」を押します。別名で配置すると、古い画像と区別して確認できます。

**掲載停止：** 「制作実績」の一覧で対象の1件にチェックを入れ、「一括操作 → 編集 → 適用」を選びます。「ステータス」を「下書き」にして「更新」を押し、一覧で下書きになったことを確認します。これで非公開実績一覧・詳細から掲載を止められます。画像ファイルは専用フォルダーに残るので、削除する場合は他の実績で同じ保管キーを使っていないか確認します。

公開実績を非公開へ切り替える場合は、専用フォルダーへの画像移動も必要です。掲載範囲の変更だけでは、公開メディアに残った元画像・縮小画像のURLを保護できません。既存画像の扱いは [Private Worksの設定と運用](./private-works.md#非公開画像の保管) を参照してください。

## 表示できない場合の確認

| 症状 | 確認すること |
| --- | --- |
| 一覧に出ない | 掲載範囲が非公開実績、投稿の公開状態が非公開になっているか。下書きのままになっていないか |
| 画像が出ない | FTPの配置先、ファイル名の大文字・小文字、拡張子、保管キーが一致しているか。日本語・空白・URLを入力していないか |
| 画像だけ404になる | 保管キーに対応するファイルがあり、サーバーから読み取れるか |
| 認証が通らない | Basic認証のユーザー名・パスワードを使っているか。WordPress管理画面の認証情報と取り違えていないか |
| 認証後も503になる | サーバーのBasic認証設定がテーマに認識されていない状態。公開状態を変えて回避せず、サーバー設定を確認する |
| 詳細ページが404になる | 保存後のスラッグとリンク先が一致しているか。必要に応じて「設定 → パーマリンク設定」で設定を変えずに保存する |

画像の配信URLは `/private-works/media/投稿ID/` です。投稿IDは、管理画面で対象実績を編集したときのURLの `post=数字` で確認できます。画像URLにもBasic認証が必要です。
